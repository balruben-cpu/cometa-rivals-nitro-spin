## 🎮 Overview

**Cometa Rivals: Overdrive** (also known as *Nitro Spin*) is a high-speed 3D vehicular combat and kart racing game designed for **Nintendo Switch 2** and **iOS / Android**.

This repository contains the interactive glassmorphic web pitch deck presentation for investors and publishers.

---

## 🌟 Pitch Deck Highlights

1. **Cover & Vision:** High-impact hero visual and core pitch goals.
2. **Market Opportunity:** Hybrid sweet spot combining *Sonic Forces Speed Battle* momentum + *Disney Speedstorm* character classes + *Smash Karts* ricochet combat.
3. **Core Gameplay & Mechanics:** The Clan Wheel (Milenarios, Depredadores, Fugitivos, Míticos), Ricochet physics, and 4 Vehicle Archetypes (Speedsters, Karts, Tanks, Buggies).
4. **21 Champion Roster:** 21 fully modeled & rigged 3D characters with custom battle cars (including new champion **Prisma ✨**).
5. **In-Game Sponsorship Engine:** Trackside billboards, vehicle decals, and 3D Spinning Top Pickups serving as an active showroom for Cometa physical toys.
6. **Multiplatform Strategy:** $0 license fee entry via Nintendo Developer Portal & 60 FPS mobile Unity engine.
7. **Production Budget:** $132,000 USD target accelerated by pre-existing 3D character models and AI workflows.
8. **Monetization & LiveOps:** Rival Pass, vehicle skin customization, and daily habit loops.
9. **Execution Roadmap:** 6-month vertical slice to cross-play launch.
